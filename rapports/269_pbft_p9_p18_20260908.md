## Code (durcissement)

- PREPARE refusé si digest ≠ PRE-PREPARE accepté (`not_accepted`).
- Chargement disque : certificats / prepared **non vérifiés sont ignorés**.
- Agent : `idempotency_conflict` si même `event_id` et payload différent ; `agent_identity_conflict` si même `agent_id` et owner/provider différents.
- `pbft_cert` est un **sidecar** du hash : `H(contenu)` n’inclut pas le certificat ; le binding est `(view, seq, digest==hash)`.
