## 1. Les 3 anomalies corrigées

### Anomalie 1 — `record_id` ne couvrait pas tout le record (R355.1)

**AVANT :**
```python
def _compute_id(self) -> str:
    payload = {
        "session_id": ..., "agent_id": ..., "context_sha256": ...,
        "ts_start_ns": ..., "first_reflex_sha": ..., "reference_canonicals": ...,
    }
    # ABSENT : observations, action, outcome, learning, earliest, ts_end
```

**APRÈS :**
```
record_id   = hash(session + agent + context + ts_start + first_reflex_sha + refs)
              → stable pendant la phase ouverte — référençable avant clôture

final_hash  = hash(TOUS les champs : record_id + context_summary + first_reflex_sha
                   + earliest_sha + observations_sha + action + outcome + learning
                   + ts_end + chain_block + ...)
              → calculé dans seal() uniquement
              → c'est la preuve cryptographique vérifiable du cycle complet
```

---

### Anomalie 2 — `seal()` n'était pas immuable (R355.2)

**AVANT :** `seal()` modifiait des champs et retournait self — rien n'empêchait une
2ème modification ou un 2ème appel.

**APRÈS :**
```python
class SealedRecordError(RuntimeError):
    """Levée si on tente de modifier un ReasoningRecord après seal()."""

def seal(self, ...) -> ReasoningRecord:
    self._check_not_frozen("seal")   # ← lève SealedRecordError si déjà scellé
    self.ts_end_ns = time.time_ns()
    self.outcome = ...
    self.final_hash = self._compute_final_hash()  # ← hash complet
    self.frozen = True               # ← gelé définitivement
    return self

# Tentatives interdites après seal() :
r.add_observation(...)   → SealedRecordError("add_observation")
r.add_reference(...)     → SealedRecordError("add_reference")
r.seal()                 → SealedRecordError("seal")
```

### Anomalie 3 — `/seal` API perdait `first_reflex` + `earliest` + `refs` + `obs` (R355.3)

**AVANT :**
```python
# /seal créait un nouveau record VIDE — sans first_reflex, earliest, refs, obs
sealed = ReasoningRecord(
    session_id=original.get("session_id", ""),
    action=RecordAction(original.get("action")),
    outcome=outcome_enum,
    learning=body.learning,
    # ABSENT : first_reflex, earliest, reference_ids, observations, context_sha256...
)
```

**APRÈS :**
```python
# /seal reconstruit le record complet depuis le JSONL puis le scelle
sealed = store.seal_in_place(
    record_id,
    outcome=outcome_enum,
    outcome_detail=...,
    learning=...,
    new_rule_candidate=...,
)
# seal_in_place() utilise record_from_dict() qui préserve :
# first_reflex, earliest, reference_ids, observations, context_sha256, context_summary
```
