# Rapport 290 — Thinking intégral = visibilité `private`, pas un résumé public

Le mot « thinking privé » dans R289 voulait dire **le flux interne du modèle que Cursor n’injecte pas dans la VM**. Ce n’était **pas** « il ne faut jamais mettre le thinking dans ARTCB ».
